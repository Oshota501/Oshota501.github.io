LaTeXグラフ

数式を貼り付けると、x 以外の文字がパラメータ（スライダー）になります。

数式 1行に1つ

    使える書き方
    • y = … / f(x) = … / 式だけ（どれでも可）
    • \frac{}{} \sqrt{} \sqrt[n]{} ^{} |x| \lfloor x \rfloor n!
    • \sin \cos \tan \ln \log_2 \exp \sinh \arctan \max \min など
    • \pi と e は定数。a_1 や \alpha はパラメータ
    • f(x) = … と定義した関数は別の行から f(x+1) のように呼べます
    • $…$ や \[ … \] ごと貼り付けてもOK

    パラメータ

    x 以外の文字を式に入れると、ここにスライダーが出ます。

    〜 〜
