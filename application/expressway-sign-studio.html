1案内標識メーカー

code → sign → png

記述コード

書き方（クリックで開く）
panel で標識板を1枚追加し、その下の各行が板の中身になります。 1行に部品を並べると横に、行を分けると縦に並びます。--- で段を分けます。

部品

text(奈良, Nara)地名（上＝日本語、下＝ローマ字）。ローマ字は省略可
exit(13)
exit(13, 奈良, Nara)		出口・入口番号の枠。地名まで一括でも書けます
shield(1, Loop)路線番号の枠（下＝番号、上＝小さい文字）
route(E26, 近畿道, KINKI EXP)Eナンバー枠＋路線名
arrow(down)行の中に置く矢印（up/down/left/right）
big(JCT) / dist(300m)大きい文字／距離の文字
label(自由文字, 28, #fff)好きな大きさ・色の文字
rect(120, 8, #fff)
circle(40, #fff)		四角・丸（色は省略可）
gap(24)横方向のすき間
西船場 / Nishisemba括弧のない行は地名として扱われます

板と段

panel緑の板。panel etc=黄 / blue / white / brown / black
arrow up板の左側に、高さいっぱいの矢印
---ここから下を次の段に置く

変数とくりかえし（整数のみ）

$n = 11変数に代入。$n = $n + 1 のように計算も可（+ - * / % と括弧）
$n$ / $n文字の中で値に置き換わる。例 text(出口$n$番)
{$n * 2 + 1}波括弧の中は式として計算されます
for $i = 1 to 4
  …
end		くりかえし。step 2 を末尾に付けると増分を変更（マイナスも可）
repeat 3
  …
end		回数だけくりかえし
if $i == 2
  …
else
  …
end		条件分岐（== != < > <= >=）

自由配置（座標）

canvas 700, 320画像の最低サイズを指定
at 40, 60: exit(13) text(奈良, Nara)座標(x,y)に部品を置く。左上が原点
at 350, 60, center, white:
  big(ETC)		x,yのあとに center/right（横基準）と色を追加できます
panel at 40, 120板そのものを座標に置く（並びから外れます）
origin 100, 50以降の座標の原点をずらす（座標系の移動）
座標の値にも式が使えます。例：at {40 + $i * 150}, 60: exit({11 + $i})

プレビュー

保存すると、いま表示されている標識がそのまま画像になります。
