1案内標識メーカー

code → sign → png

記述コード

書き方（クリックで開く）
panel で標識板を1枚追加し、その下の各行が板の中身になります。--- で改行して2段目に置けます。
1行に部品を並べると横に、行を分けると縦に並びます。
panel緑の標識板を追加（panel etc＝黄色 / panel blue＝青 / panel white＝白）
arrow up板の左側に、板の高さいっぱいの矢印を置く（up/down/left/right）
text(奈良, Nara)地名（上＝日本語、下＝ローマ字）。ローマ字は省略可
exit(13)出口・入口番号の枠
exit(13, 奈良, Nara)番号枠＋地名をまとめて
shield(1, Loop)路線番号の枠（下＝番号、上＝小さい文字）
route(E26, 近畿道, KINKI EXP)Eナンバー枠＋路線名
arrow(down)行の中に置く矢印
big(JCT)大きい文字
dist(300m)距離などの文字
gap(24)横方向のすき間
西船場 / Nishisemba括弧を書かない行は地名として扱われます
# メモ行頭が # の行は無視されます

プレビュー

保存すると、いま表示されている標識がそのまま画像になります。
